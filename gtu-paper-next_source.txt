# GTU Papers & Syllabus Downloader (fixed build)

Next.js 16 app that fetches previous-year GTU question papers and the official
syllabus for any course + subject codes. No login, no captcha, no database.
Requires Node 22.23.4+ / 24.22.1+ / 26.12.1+ (Node 24 LTS recommended).

## What each subject gets

- Syllabus
- Single paper for every session found (2017 up to the current year, computed at run time)
- Merge Summer: all summer papers, oldest → newest, one PDF
- Merge Winter: all winter papers, oldest → newest, one PDF
- Merge All: every paper, oldest → newest (S2017, W2017, S2018 …), one PDF

Select any files (checkboxes / Select all) and pick one of three actions:

1. Individually: each file is saved directly (no new tab)
2. Merge in order: one PDF (per subject: syllabus first, then papers oldest → newest; duplicates removed)
3. .zip: one archive built in the browser with a progress bar

## How it works (and why)

```
Browser ──Range 0-1023──> old26.gtu.ac.in/uploads/<S|W><year>/<course>/<code>.pdf
   │                      (discovery: %PDF header + total size only; GTU sends CORS *)
   ├──GET (full file)────> same URL, only on Download / View / merge
   ├──GET──> /api/pdf/<course>/<code>/SYLLABUS   (our server streams the S3 syllabus,
   │                                            Content-Disposition: attachment; S3 has no CORS)
   ├── @cantoo/pdf-lib in a module Web Worker -> Merge Summer / Winter / All / Merge in order
   ├── client-zip                             -> .zip with progress
   └── blob: URL + <a download>               -> saves with the right filename, page never navigates
```

- GTU's file hosts answer **403 to many datacenter IPs** (checked 2026-10-30 from a
  Google Cloud server: 403 even with a browser user-agent; also 403 for
  "HeadlessChrome" user-agents). Visitors' own browsers are allowed, so papers are
  fetched client-side. The server only proxies the syllabus. If a browser fetch
  fails, the app retries and then tries `/api/pdf/...` on the server as a fallback.
- Discovery only downloads the first 1 KB of each paper (a Range probe) and
  records its size. The full PDF is fetched on the first Download, View or
  merge, so listing 100+ papers no longer costs ~200 MB of mobile data.
  If GTU ignores or rejects Range, the engine automatically falls back to the
  old full-download behaviour (the probe result is cached for the session).
- Full PDFs are kept as `Blob`s in an LRU cache capped at 256 MB, so the
  browser can spill large files to disk instead of pinning them in the JS heap.
  Everything disappears on reload (the "temporary cache"). The syllabus proxy
  sets `Cache-Control: s-maxage=86400`, so a CDN (Vercel) keeps a copy for a
  day at most.
- No server-side merge or ZIP, so no serverless timeout / 4.5 MB body limit / RAM
  issue. Merging runs in a module Web Worker; if a worker cannot start, it
  falls back to the main thread.
- `/` is statically rendered. Shareable `?course=…&subjects=…` state is read in
  the client inside a `<Suspense>` boundary, not with `await searchParams`.

## Security

- A CSP is sent from `next.config.ts`. `connect-src` allows only this origin
  plus the GTU paper host, so an injected script cannot exfiltrate data.
  `script-src` uses `'unsafe-inline'` because Next's bootstrap and the no-flash
  theme script are inline; a nonce would force every page to be dynamic.
- The PDF proxy follows no redirects (`redirect: "manual"`), so an upstream
  redirect cannot move a request off the allow-listed hosts.
- `/api/visitors` accepts only UUID visitor ids, caps the request body at 1 KB,
  runs `PFADD` + `PFCOUNT` in one Upstash pipeline, and is rate-limited with
  `@upstash/ratelimit`. The in-memory limiter used by `/api/pdf` prefers
  `x-real-ip` and the last `x-forwarded-for` entry, so it is not spoofable by a
  client-supplied first value.
- `/api/health` no longer exposes the Node version.

## Run

```bash
npm ci                 # Node 22.23.4+ / 24.22.1+ / 26.12.1+
npm run dev            # http://localhost:3000
npm run lint && npm run typecheck && npm test
npm run build && npm start
```

npm is the only supported package manager: `package-lock.json` is the single
lockfile and `packageManager` pins the npm version.

Self-contained Node server (any VPS / box):

```bash
NEXT_OUTPUT=standalone NEXT_PUBLIC_APP_URL=https://your.domain npm run build
cp -r .next/static .next/standalone/.next/static
cd .next/standalone && PORT=3000 HOSTNAME=0.0.0.0 node server.js
```

## Deploy to Vercel

Import the repo, framework Next.js, no build settings needed. Environment variables:

| Name | Required | Purpose |
|---|---|---|
| `NEXT_PUBLIC_APP_URL` | recommended | Canonical site URL for metadata, robots.txt and sitemap.xml (default `https://paper.devang.live`) |
| `UPSTASH_REDIS_REST_URL`, `UPSTASH_REDIS_REST_TOKEN` | optional | Visitor counter; hidden when unset |

No Turnstile keys any more; the captcha was removed.

## Structure

```
src/app/api/pdf/[course]/[subject]/[session]/route.ts  streamed PDF proxy (syllabus; paper fallback)
src/app/api/visitors/route.ts  UUID-validated, rate-limited HyperLogLog counter
src/lib/paper-engine.ts     Range probes, lazy full fetch, Blob cache, merge orchestration
src/lib/pdf-merge.ts        shared pdf-lib merge routine
src/lib/merge-worker.ts     module Web Worker for merging
src/lib/zip-client.ts       client-zip archive
src/lib/sessions.ts         session range up to the current year + chronological order
src/server/rate-limit.ts    in-memory limiter + trusted client-key derivation
src/components/download/    results panel, rows, bulk toolbar
src/proxy.ts                404 (not 500) for malformed /papers/... URLs
```

// Next.js config: security headers. No captcha / third-party scripts.
// Nothing secret here — secrets only enter via environment variables.

import type { NextConfig } from "next";
import { DOWNLOAD_CONFIG } from "./src/config/download.config";

const isProduction = process.env.NODE_ENV === "production";

// The browser fetches papers straight from GTU, so that origin must stay in
// connect-src. Everything else is same-origin. 'unsafe-inline' is required by
// Next's bootstrap scripts and the no-flash theme script; a nonce-based CSP
// would force every page to render dynamically, which this app does not need.
const CSP = [
  "default-src 'self'",
  `script-src 'self' 'unsafe-inline'${isProduction ? "" : " 'unsafe-eval'"}`,
  "style-src 'self' 'unsafe-inline'",
  "img-src 'self' data: blob:",
  "font-src 'self'",
  "media-src 'self'",
  "worker-src 'self' blob:",
  `connect-src 'self' ${new URL(DOWNLOAD_CONFIG.gtuBaseUrl).origin}${isProduction ? "" : " ws: wss:"}`,
  "frame-src 'self' blob:",
  "frame-ancestors 'none'",
  "base-uri 'self'",
  "form-action 'self'",
  "object-src 'self' blob:",
  "manifest-src 'self'",
].join("; ");

const SECURITY_HEADERS = [
  { key: "Content-Security-Policy", value: CSP },
  { key: "X-Content-Type-Options", value: "nosniff" },
  { key: "X-Frame-Options", value: "DENY" },
  { key: "Referrer-Policy", value: "strict-origin-when-cross-origin" },
  {
    key: "Permissions-Policy",
    value: "camera=(), microphone=(), geolocation=()",
  },
  { key: "Cross-Origin-Opener-Policy", value: "same-origin" },
  ...(isProduction
    ? [
        {
          key: "Strict-Transport-Security",
          value: "max-age=31536000; includeSubDomains",
        },
      ]
    : []),
];

const nextConfig: NextConfig = {
  // NEXT_OUTPUT=standalone builds a self-contained server (node server.js)
  // for a plain Node box; Vercel ignores this and uses its own output.
  ...(process.env.NEXT_OUTPUT === "standalone" ? { output: "standalone" as const } : {}),
  // Hides the floating dev-mode badge so the UI looks production-clean
  // even while running `next dev`.
  devIndicators: false,
  async headers() {
    return [{ source: "/:path*", headers: SECURITY_HEADERS }];
  },
};

export default nextConfig;

// Route guard for deep paper links: /papers/[course]/[subject].
// Invalid segments rewrite to the internal not-found route BEFORE the page
// streams, so crawlers and clients receive a real 404 status (calling
// notFound() inside the streaming page can only produce a soft 404).

import { NextResponse } from "next/server";
import type { NextRequest } from "next/server";
import { COURSES, SUBJECT_CODE_PATTERN } from "@/constants/app.constants";

const PAPER_SEGMENTS = 3;
const COURSE_INDEX = 1;
const SUBJECT_INDEX = 2;

// Validates /papers/:course/:subject; anything else falls through.
function isValidPaperPath(pathname: string): boolean {
  const segments = pathname.split("/").filter(Boolean);
  if (segments.length !== PAPER_SEGMENTS || segments[0] !== "papers") {
    return true;
  }
  // decodeURIComponent throws on malformed input like "%E0%A4" → was a 500.
  const courseSegment = segments[COURSE_INDEX];
  const subjectSegment = segments[SUBJECT_INDEX];
  if (!courseSegment || !subjectSegment) return false;

  let course: string;
  let subject: string;
  try {
    course = decodeURIComponent(courseSegment).toUpperCase();
    subject = decodeURIComponent(subjectSegment).toUpperCase();
  } catch {
    return false;
  }
  const knownCourse = (COURSES as readonly string[]).includes(course);
  return knownCourse && SUBJECT_CODE_PATTERN.test(subject);
}

export function proxy(request: NextRequest) {
  if (!isValidPaperPath(request.nextUrl.pathname)) {
    return NextResponse.rewrite(new URL("/_not-found", request.url));
  }
  return NextResponse.next();
}

export const config = {
  matcher: "/papers/:path*",
};

// GET /api/pdf/:course/:subject/:session  (session = W2024 | S2025 | SYLLABUS)
// Streams one upstream PDF through this origin with
//   Content-Disposition: attachment  -> real download, never a new tab
//   Cache-Control: public, s-maxage  -> the CDN keeps a copy for a day and
//                                       then drops it (this IS the "temporary
//                                       storage with auto-delete"; no DB).
// Streaming means no 4.5 MB body limit and ~64 KB memory per request.
// ?inline=1 serves it inline for the "View" button.

import { NextRequest, NextResponse } from "next/server";
import { parsePaperRef, upstreamUrl, outputFilename } from "@/server/gtu-urls";
import { checkRateLimit, clientKey } from "@/server/rate-limit";

export const runtime = "nodejs";
export const maxDuration = 60;

const UPSTREAM_TIMEOUT_MS = 20_000;
const CDN_CACHE = "public, max-age=3600, s-maxage=86400, stale-while-revalidate=604800";
const UA =
  "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 " +
  "(KHTML, like Gecko) Chrome/140.0 Safari/537.36";

export async function GET(
  request: NextRequest,
  context: { params: Promise<{ course: string; subject: string; session: string }> },
) {
  if (!checkRateLimit(clientKey(request.headers, "pdf"), 120, 60_000)) {
    return NextResponse.json({ error: "Too many requests." }, { status: 429 });
  }
  const p = await context.params;
  const ref = parsePaperRef(p.course, p.subject, p.session);
  if (!ref) {
    return NextResponse.json({ error: "Invalid paper reference." }, { status: 400 });
  }

  let upstream: Response;
  try {
    upstream = await fetch(upstreamUrl(ref), {
      headers: { "User-Agent": UA, Accept: "application/pdf,*/*" },
      signal: AbortSignal.timeout(UPSTREAM_TIMEOUT_MS),
      cache: "no-store",
      // Never let an upstream redirect take the request off the allow-list.
      redirect: "manual",
    });
  } catch {
    return NextResponse.json({ error: "GTU server did not respond. Retry." }, { status: 504 });
  }
  if (upstream.status >= 300 && upstream.status < 400) {
    return NextResponse.json(
      { error: "GTU redirected the request; refusing to follow." },
      { status: 502 },
    );
  }
  if (upstream.status === 404 || upstream.status === 403) {
    return NextResponse.json(
      { error: "Paper not found on GTU." },
      { status: 404, headers: { "Cache-Control": "public, s-maxage=3600" } },
    );
  }
  if (!upstream.ok || !upstream.body) {
    return NextResponse.json({ error: `GTU error ${upstream.status}. Retry.` }, { status: 502 });
  }

  // Peek the first chunk: refuse HTML error pages served as 200.
  const reader = upstream.body.getReader();
  const first = await reader.read();
  const head = first.value ? new TextDecoder().decode(first.value.subarray(0, 5)) : "";
  if (!head.startsWith("%PDF")) {
    await reader.cancel().catch(() => undefined);
    return NextResponse.json({ error: "GTU returned a non-PDF file." }, { status: 502 });
  }
  const body = new ReadableStream<Uint8Array>({
    start(controller) {
      if (first.value) controller.enqueue(first.value);
    },
    async pull(controller) {
      const { done, value } = await reader.read();
      if (done) controller.close();
      else controller.enqueue(value);
    },
    cancel(reason) {
      return reader.cancel(reason);
    },
  });

  const inline = request.nextUrl.searchParams.get("inline") === "1";

// Unique visitor counter — backed by Upstash Redis HyperLogLog.
//
// POST /api/visitors  { visitorId: UUID }
//   → Adds the visitorId to the HyperLogLog set and returns the new count.
//   → HyperLogLog: O(1) space (~12 KB max), ±0.81% error, no PII stored.
//
// GET /api/visitors
//   → Returns current unique count without modifying the set.
//
// Both methods are rate-limited with Upstash's distributed sliding window, so
// one client cannot inflate the count or burn the Redis quota. PFADD + PFCOUNT
// run in a single pipeline request. If env vars are absent (local dev), both
// endpoints return count: 0 instead of crashing.

import { Ratelimit } from "@upstash/ratelimit";
import { Redis } from "@upstash/redis";
import { type NextRequest, NextResponse } from "next/server";
import { clientKey } from "@/server/rate-limit";

export const runtime = "nodejs";

const REDIS_URL = process.env.UPSTASH_REDIS_REST_URL;
const REDIS_TOKEN = process.env.UPSTASH_REDIS_REST_TOKEN;
const HLL_KEY = "gtu:unique_visitors";

// RFC 4122 shape (versions 1–8, variant 8/9/a/b). The client sends a v4 UUID.
const UUID_PATTERN =
  /^[0-9a-f]{8}-[0-9a-f]{4}-[1-8][0-9a-f]{3}-[89ab][0-9a-f]{3}-[0-9a-f]{12}$/i;

// A visitor payload is tiny; reject anything that could be used to waste RAM.
const MAX_BODY_BYTES = 1_024;

const redis =
  REDIS_URL && REDIS_TOKEN
    ? new Redis({ url: REDIS_URL, token: REDIS_TOKEN })
    : null;

const ratelimit = redis
  ? new Ratelimit({
      redis,
      limiter: Ratelimit.slidingWindow(10, "1 m"),
      prefix: "gtu:rl:visitors",
      analytics: false,
    })
  : null;

// Fails open: the counter is decorative, so a Redis hiccup must not break it.
async function allow(headers: Headers, scope: string): Promise<boolean> {
  if (!ratelimit) return true;
  try {
    const result = await ratelimit.limit(clientKey(headers, scope));
    return result.success;
  } catch {
    return true;
  }
}

function tooMany(): NextResponse {
  return NextResponse.json(
    { error: "Too many requests." },
    { status: 429, headers: { "Retry-After": "60" } },
  );
}

// GET — read current unique visitor count (no mutation).
export async function GET(request: NextRequest): Promise<NextResponse> {
  if (!(await allow(request.headers, "visitors:get"))) return tooMany();
  if (!redis) return NextResponse.json({ count: 0 });

  try {
    const count = await redis.pfcount(HLL_KEY);
    return NextResponse.json({ count });
  } catch {
    // Degraded: return 0 so the UI still renders without crashing.
    return NextResponse.json({ count: 0 });
  }
}

// POST — register a visitor + return the updated count.
export async function POST(request: NextRequest): Promise<NextResponse> {
  if (!(await allow(request.headers, "visitors:post"))) return tooMany();

  const declaredLength = Number(request.headers.get("content-length") ?? 0);
  if (declaredLength > MAX_BODY_BYTES) {
    return NextResponse.json({ error: "Request body too large" }, { status: 413 });
  }

  let body: unknown;
  try {
    body = await request.json();
  } catch {
    return NextResponse.json({ error: "Invalid JSON" }, { status: 400 });
  }

  const visitorId = (body as { visitorId?: unknown } | null)?.visitorId;
  if (typeof visitorId !== "string" || !UUID_PATTERN.test(visitorId)) {
    return NextResponse.json(
      { error: "visitorId must be a UUID" },
      { status: 400 },
    );
  }

  // Validated input, but no Redis configured (local dev): stay degraded.
  if (!redis) return NextResponse.json({ count: 0 });

  try {
    // PFADD returns 1 when the set changed; PFCOUNT returns the new total.
    // One pipeline round trip instead of two.
    const [, count] = await redis
      .pipeline()
      .pfadd(HLL_KEY, visitorId)
      .pfcount(HLL_KEY)
      .exec<[number, number]>();
    return NextResponse.json({ count });
  } catch {
    return NextResponse.json({ count: 0 });
  }
}

  color: string;
  files: DownloadFileItem[];

// Sorts single papers newest-first (W2024 is newer than S2024).
function sortSingleFiles(files: DownloadFileItem[]): DownloadFileItem[] {
  const bySession = new Map(files.map((f) => [f.session ?? "", f]));
  return sortNewestFirst([...bySession.keys()]).map((s) => bySession.get(s) as DownloadFileItem);
}

// Builds the card list: syllabus first, then one card per subject section.
function buildCards(
  data: DownloadResponse,
  subjects: string[],
): ResultCard[] {
  const cards: ResultCard[] = [];
  const syllabus = data.files
    .filter((file) => file.format === "syllabus")
    .sort((a, b) => subjects.indexOf(a.subject) - subjects.indexOf(b.subject));
  if (syllabus.length > 0) {
    cards.push({
      key: "syllabus",
      badge: null,
      title: "Syllabus",
      color: "var(--gtu-section-syllabus)",
      files: syllabus,
    });
  }
  const bySubject = new Map<string, DownloadFileItem[]>();
  for (const file of data.files) {
    if (file.format === "syllabus") continue;
    const key = file.subject;
    const list = bySubject.get(key) ?? [];
    list.push(file);
    bySubject.set(key, list);
  }
  const order = (s: string) => {
    const i = subjects.indexOf(s);
    return i === -1 ? 999 : i;
  };
  const subjectEntries = [...bySubject.entries()].sort(([a], [b]) => order(a) - order(b));
  for (const [subject, files] of subjectEntries) {
    for (const section of FORMAT_SECTIONS) {
      const sectionFiles = files.filter((file) =>
        section.formats.includes(file.format),
      );
      if (sectionFiles.length > 0) {
        cards.push({
          key: `${subject}-${section.title}`,
          badge: subject,
          title: section.title,
          color: section.color,
          // Singles sorted newest-first; other formats keep natural order.
          files: section.formats.includes("single")
            ? sortSingleFiles(sectionFiles)
            : sectionFiles,
        });
      }
    }
  }
  return cards;
}

        // the form returns to its pristine "nothing selected" state.

        if (course) resetCourse();
      } else if (!courseManuallySet) {
        // Old-style codes only, user hasn't manually chosen yet → prompt them.
        if (course) resetCourse();
      }
      // else: old-style codes + user already chose manually → keep their pick.
    }
    // detected.length > 1 → conflict alert handles it; don't touch course.
  }

  return (
    <div className="grid grid-cols-1 gap-6 lg:grid-cols-[380px_minmax(0,1fr)]">
      <section
        aria-label="Paper selection"
        // Sticks the form beside the scrolling results on desktop:

        className="gtu-fade-up min-w-0 lg:sticky lg:top-[72px] lg:max-h-[calc(100vh-88px)] lg:self-start lg:overflow-y-auto"

              {courseConflict && (
                <p role="alert" className="text-xs text-[var(--gtu-error)]">
                  Codes from multiple courses ({detectedCourses.join(", ")})
                  can&apos;t be fetched together.
                </p>
              )}
              {codes.length > 0 && !course && !courseConflict && (
                <p role="alert" className="text-xs text-[var(--gtu-error)]">
                   Please select a course from the dropdown above.
                </p>

// Theme provider: auto-detects system preference on first visit,
// then respects the user's manual light/dark toggle.

"use client";

import {
  createContext,
  useContext,
  useEffect,
  useState,
  type ReactNode,
} from "react";

type Theme = "light" | "dark";

interface ThemeContextValue {
  theme: Theme;
  toggle: () => void;
}

const ThemeContext = createContext<ThemeContextValue | null>(null);

const STORAGE_KEY = "gtu-theme";

function getInitialTheme(): Theme {
  // Server-side: default dark (no window).
  if (typeof window === "undefined") return "dark";
  try {
    const saved = localStorage.getItem(STORAGE_KEY);
    if (saved === "light" || saved === "dark") return saved;
  } catch {
    // Storage blocked (private mode / policy) — fall through to the OS.
  }
  // First visit: follow the OS.
  return window.matchMedia("(prefers-color-scheme: dark)").matches
    ? "dark"
    : "light";
}

export function ThemeProvider({ children }: { children: ReactNode }) {
  const [theme, setTheme] = useState<Theme>("dark");

  // Hydrate from localStorage / system on mount.
  // Deferred one frame so the first client render matches the server HTML.
  useEffect(() => {
    const id = requestAnimationFrame(() => setTheme(getInitialTheme()));
    return () => cancelAnimationFrame(id);
  }, []);

  // Apply data-theme to <html> on every change.
  useEffect(() => {
    document.documentElement.setAttribute("data-theme", theme);
  }, [theme]);

  const toggle = () => {
    setTheme((prev) => {
      const next = prev === "dark" ? "light" : "dark";
      try {
        localStorage.setItem(STORAGE_KEY, next);
      } catch {
        // Storage blocked — the theme still applies for this page view.
      }
      return next;
    });
  };

  return (
    <ThemeContext.Provider value={{ theme, toggle }}>
      {children}
    </ThemeContext.Provider>
  );
}

export function useTheme(): ThemeContextValue {
  const ctx = useContext(ThemeContext);
  if (!ctx) throw new Error("useTheme must be inside <ThemeProvider>");
  return ctx;
}

/** Formats a number with locale-aware thousands separators: 1234 → "1,234" */
function fmt(n: number): string {
  return n.toLocaleString("en-IN"); // e.g. 1,23,456 for Indian locale

/** Animates from 0 to `target` over ~800ms using requestAnimationFrame. */
function useCountUp(target: number | null): number | null {
  const [display, setDisplay] = useState<number | null>(null);
  const rafRef = useRef<number | null>(null);

  useEffect(() => {
    if (target === null) return;

    // If first render just snap to target with no animation.
    if (display === null) {
      const snap = requestAnimationFrame(() => setDisplay(target));
      return () => cancelAnimationFrame(snap);
    }

    const start = performance.now();
    const duration = 800;
    const from = display;
    // Capture in a const so TypeScript knows it is non-null inside step().
    const to = target;

    function step(now: number) {
      const elapsed = now - start;
      const progress = Math.min(elapsed / duration, 1);
      // Ease-out cubic
      const eased = 1 - Math.pow(1 - progress, 3);
      setDisplay(Math.round(from + (to - from) * eased));

  }, [target]);

  return display;
}

// Download orchestration: validation → client-side discovery → live state.
// Engine events are coalesced per animation frame, so a burst of streamed
// rows triggers one render instead of one render per file.
// Errors keep whatever results already arrived (they no longer wipe them).

"use client";

import { useCallback, useRef, useState } from "react";
import { DOWNLOAD_STATUS } from "@/constants/download.constants";
import { downloadRequestSchema } from "@/schemas/download.schema";
import { discover } from "@/lib/paper-engine";
import {
  applyDownloadEvent,
  EMPTY_DOWNLOAD_RESPONSE,
  pendingCountOf,
} from "@/lib/download-progress";
import type {
  DownloadEvent,
  DownloadRequest,
  DownloadState,
} from "@/types/download.types";

const INITIAL_STATE: DownloadState = {
  status: DOWNLOAD_STATUS.idle,
  data: null,
  error: null,
};

export function useDownload() {
  const [state, setState] = useState<DownloadState>(INITIAL_STATE);
  const inFlight = useRef<AbortController | null>(null);
  const buffered = useRef<DownloadEvent[]>([]);
  const frame = useRef<number | null>(null);

  // Applies every event buffered since the last frame in one state update.
  const flush = useCallback(() => {
    if (frame.current !== null) {
      cancelAnimationFrame(frame.current);
      frame.current = null;
    }
    const events = buffered.current;
    if (events.length === 0) return;
    buffered.current = [];
    setState((prev) => {
      let data = prev.data ?? { ...EMPTY_DOWNLOAD_RESPONSE };
      for (const event of events) data = applyDownloadEvent(data, event);
      return { ...prev, data };
    });
  }, []);

  const enqueue = useCallback(
    (event: DownloadEvent) => {
      buffered.current.push(event);
      if (frame.current !== null) return;
      if (typeof requestAnimationFrame === "undefined") {
        flush();
        return;
      }
      frame.current = requestAnimationFrame(() => {
        frame.current = null;
        flush();
      });
    },
    [flush],
  );

  const download = useCallback(
    async (payload: DownloadRequest) => {
      if (inFlight.current) return;
      const parsed = downloadRequestSchema.safeParse(payload);
      if (!parsed.success) {
        setState((prev) => ({
          ...prev,
          status: DOWNLOAD_STATUS.error,
          error: parsed.error.issues[0]?.message ?? "Check your input.",
        }));
        return;
      }
      const controller = new AbortController();
      inFlight.current = controller;
      buffered.current = [];
      setState({
        status: DOWNLOAD_STATUS.loading,
        data: { ...EMPTY_DOWNLOAD_RESPONSE },
        error: null,
      });
      // Ignore late events from a run that was reset/aborted.
      const onEvent = (event: DownloadEvent) => {
        if (inFlight.current === controller) enqueue(event);
      };
      try {
        await discover(parsed.data, onEvent, controller.signal);
        if (controller.signal.aborted) return;
        flush();
        setState((prev) => ({
          status: DOWNLOAD_STATUS.success,
          data: prev.data,
          error: null,
        }));
      } catch (error) {
        if (controller.signal.aborted) return;
        flush();
        setState((prev) => ({
          status: DOWNLOAD_STATUS.error,
          data: prev.data,
          error: error instanceof Error ? error.message : "Download failed. Retry.",
        }));
      } finally {
        if (inFlight.current === controller) inFlight.current = null;
      }
    },
    [enqueue, flush],
  );

  const pendingCount =
    state.status === DOWNLOAD_STATUS.loading ? pendingCountOf(state.data) : 0;

  // Clears results/errors back to idle and cancels any running fetch.
  const reset = useCallback(() => {
    inFlight.current?.abort();
    inFlight.current = null;
    buffered.current = [];
    if (frame.current !== null) {
      cancelAnimationFrame(frame.current);
      frame.current = null;
    }
    setState(INITIAL_STATE);
  }, []);

  return { ...state, pendingCount, download, reset };
}

  prev: DownloadResponse,
  event: DownloadEvent,

    case "start":

    case "error":
      return prev;

// Client-side paper engine.
//
// 1. discover(): the browser probes every session PDF straight from GTU
//    (CORS *) with bounded concurrency, retries and %PDF validation. A 1 KB
//    Range probe is enough to list a paper; the full file is fetched on the
//    first Download / View / merge. If GTU ignores or rejects Range, the probe
//    falls back to the old full download, so behaviour never regresses.
//    The syllabus comes through our own /api/pdf proxy (its host has no CORS).
// 2. Full bytes are kept as Blobs in an LRU-capped Map for this tab only
//    (temporary cache: gone on reload, nothing stored on any server, no DB).
//    Blobs let the browser spill large PDFs to disk instead of pinning them
//    in the JS heap.
// 3. Singles save from a same-origin blob: URL with <a download>, so the
//    browser saves the file under the right name and the page never
//    navigates or opens a tab.
// 4. Merges use @cantoo/pdf-lib in a module Web Worker (with a main-thread
//    fallback), so the UI stays responsive and there is no server limit.

import { DOWNLOAD_CONFIG } from "@/config/download.config";
import { ROUTES_CONFIG } from "@/config/routes.config";
import { chronoKey, sessionsUpTo, sortChronological } from "@/lib/sessions";
import { formatDuration } from "@/utils/format";
import type {
  DownloadEvent,
  DownloadFileItem,
  DownloadRequest,
} from "@/types/download.types";

// Full files (Blob) and probe results (size only) are tracked separately so a
// 1 KB probe can never be mistaken for a complete PDF.
const store = new Map<string, Blob>();
const probes = new Map<string, { sizeBytes: number | null }>();
const building = new Map<string, Promise<Blob>>();

// Merged copies duplicate bytes, so cap what this tab keeps. Oldest entries
// are evicted first; a single oversized file is still kept.
const MAX_CACHE_BYTES = 256 * 1024 * 1024;
let cachedBytes = 0;

const sleep = (ms: number) => new Promise((r) => setTimeout(r, ms));

async function isPdfBlob(blob: Blob): Promise<boolean> {
  if (blob.size < DOWNLOAD_CONFIG.minPdfBytes) return false;
  const head = new Uint8Array(await blob.slice(0, 4).arrayBuffer());
  return (
    head[0] === 0x25 && // %
    head[1] === 0x50 && // P
    head[2] === 0x44 && // D
    head[3] === 0x46 // F
  );
}

type FetchResult =
  | { bytes: Blob }
  | { probed: true; sizeBytes: number | null }
  | { missing: true }
  | { error: string };

function cacheGet(name: string): Blob | undefined {
  const blob = store.get(name);
  if (!blob) return undefined;
  // Refresh insertion order for LRU eviction.
  store.delete(name);
  store.set(name, blob);
  return blob;
}

function cacheSet(name: string, blob: Blob): void {
  const previous = store.get(name);
  if (previous) cachedBytes -= previous.size;
  store.delete(name);
  store.set(name, blob);
  cachedBytes += blob.size;
  probes.delete(name);

  while (cachedBytes > MAX_CACHE_BYTES && store.size > 1) {
    const oldest = store.keys().next();
    if (oldest.done) break;
    const evicted = store.get(oldest.value);
    store.delete(oldest.value);
    if (evicted) cachedBytes -= evicted.size;
  }
}

function sizeOf(name: string): number {
  return store.get(name)?.size ?? probes.get(name)?.sizeBytes ?? 0;
}

// One URL with timeout, retries (network / 5xx / non-PDF) and no retry on 404.
async function fetchPdf(url: string, signal?: AbortSignal): Promise<FetchResult> {
  let lastError = "network error";
  for (let attempt = 0; attempt <= DOWNLOAD_CONFIG.maxRetries; attempt += 1) {
    if (signal?.aborted) return { error: "cancelled" };
    const timeout = AbortSignal.timeout(DOWNLOAD_CONFIG.fetchTimeoutMs);
    const combined = signal ? AbortSignal.any([signal, timeout]) : timeout;
    try {
      const res = await fetch(url, {
        signal: combined,
        credentials: "omit",
        redirect: "follow",
      });
      if (res.status === 404) return { missing: true };
      if (res.ok) {
        const blob = await res.blob();
        if (await isPdfBlob(blob)) return { bytes: blob };
        lastError = "not a PDF";
      } else {
        lastError = `HTTP ${res.status}`;
        if (res.status === 403 || res.status === 400) return { error: lastError };
      }
    } catch (error) {
      lastError = error instanceof Error ? error.name : "network error";
    }
    if (attempt < DOWNLOAD_CONFIG.maxRetries) {
      await sleep(400 * 2 ** attempt + Math.random() * 200);
    }
  }
  return { error: lastError };
}

// Once a host proves it ignores or blocks Range, stop probing for the rest of
// the session instead of paying for a failed probe per file.
let rangeSupported: boolean | null = null;

function contentRangeTotal(header: string | null): number | null {
  if (!header) return null; // CORS may not expose Content-Range.
  const match = /\/(\d+)$/.exec(header);
  if (!match?.[1]) return null;
  const total = Number(match[1]);
  return Number.isFinite(total) ? total : null;
}

// Cheap discovery: ask for the first 1 KB, validate the %PDF header, and keep
// only the total size. The full file is fetched lazily on first use.
async function probePdf(url: string, signal?: AbortSignal): Promise<FetchResult> {
  if (rangeSupported === false) return fetchPdf(url, signal);

  const timeout = AbortSignal.timeout(DOWNLOAD_CONFIG.fetchTimeoutMs);
  const combined = signal ? AbortSignal.any([signal, timeout]) : timeout;
  try {
    const res = await fetch(url, {
      signal: combined,
      credentials: "omit",
      redirect: "follow",
      headers: { Range: "bytes=0-1023" },
    });
    if (res.status === 404) return { missing: true };

    if (res.status === 206) {
      rangeSupported = true;
      const blob = await res.blob();
      if (!(await isPdfBlob(blob))) return { error: "not a PDF" };
      return { probed: true, sizeBytes: contentRangeTotal(res.headers.get("content-range")) };
    }

    if (res.ok) {
      // Range was ignored and the whole file arrived anyway — keep it.
      rangeSupported = false;
      const blob = await res.blob();
      if (!(await isPdfBlob(blob))) return { error: "not a PDF" };
      return { bytes: blob };
    }

    // 403/416/5xx: use the normal path, which owns the retry policy.
    rangeSupported = false;
    return fetchPdf(url, signal);
  } catch {
    // A rejected Range request (e.g. CORS preflight) must not lose the paper.
    rangeSupported = false;
    return fetchPdf(url, signal);
  }
}

function mergeDetail(sessions: string[]): string {
  if (sessions.length === 0) return "";
  const first = sessions[0];
  const last = sessions[sessions.length - 1];
  const n = sessions.length;
  const range = n === 1 ? first : `${first} → ${last}`;
  return `${range} · ${n} paper${n === 1 ? "" : "s"}`;
}

function mergedItems(course: string, subject: string, found: string[]): DownloadFileItem[] {
  const chrono = sortChronological(found);
  const summer = chrono.filter((s) => s.startsWith("S"));
  const winter = chrono.filter((s) => s.startsWith("W"));
  const groups = [
    { format: "merge-summer" as const, suffix: "MERGE_SUMMER", sessions: summer },
    { format: "merge-winter" as const, suffix: "MERGE_WINTER", sessions: winter },
    { format: "merge-all" as const, suffix: "MERGE_ALL", sessions: chrono },
  ];
  return groups
    .filter((g) => g.sessions.length > 0)
    .map((g) => {
      const sources = g.sessions.map((s) => paperFilename(course, subject, s));
      return {
        filename: `${course}_${subject}_${g.suffix}.pdf`,
        format: g.format,
        course,
        subject,
        sources,
        sizeBytes: sources.reduce((sum, name) => sum + sizeOf(name), 0),
        detail: mergeDetail(g.sessions),
      };
    });
}

// Probes every session (current year back to firstYear) + syllabus for each
// subject, emitting events as files land.
export async function discover(
  request: DownloadRequest,
  onEvent: (event: DownloadEvent) => void,
  signal?: AbortSignal,
): Promise<void> {
  const started = performance.now();
  const sessions = sessionsUpTo();
  const course = request.course.toUpperCase();
  const subjects = request.subjects.map((s) => s.toUpperCase());
  onEvent({ type: "start", totalPdfs: subjects.length * (sessions.length + 1) });

  type Job = { subject: string; session: string };
  const jobs: Job[] = [];
  for (const subject of subjects) {
    jobs.push({ subject, session: "SYLLABUS" });
    for (const session of sessions) jobs.push({ subject, session });
  }
  const remaining = new Map(subjects.map((s) => [s, sessions.length + 1]));
  const found = new Map<string, string[]>(subjects.map((s) => [s, []]));
  let successCount = 0;
  let errors = 0;

  const finishJob = (subject: string) => {
    const left = (remaining.get(subject) ?? 1) - 1;
    remaining.set(subject, left);
    if (left === 0) {
      for (const item of mergedItems(course, subject, found.get(subject) ?? [])) {
        onEvent({ type: "file", file: item });
      }
    }
  };

  async function runJob({ subject, session }: Job) {
    const filename = paperFilename(course, subject, session);
    const isSyllabus = session === "SYLLABUS";
    const url = isSyllabus
      ? ROUTES_CONFIG.api.pdf(course, subject, "SYLLABUS")
      : gtuUrl(course, subject, session);
    let result: FetchResult;
    const cached = cacheGet(filename);
    const probed = probes.get(filename);
    if (cached) result = { bytes: cached };
    else if (probed) result = { probed: true, sizeBytes: probed.sizeBytes };
    else if (isSyllabus) result = await fetchPdf(url, signal);
    else result = await probePaper(course, subject, session, signal);

    if ("bytes" in result) {
      cacheSet(filename, result.bytes);
      successCount += 1;
      if (!isSyllabus) found.get(subject)?.push(session);
      onEvent({
        type: "file",
        file: {
          filename,
          format: isSyllabus ? "syllabus" : "single",
          course,
          subject,
          session,
          url,
          sizeBytes: result.bytes.size,
        },
      });
    } else if ("probed" in result) {
      probes.set(filename, { sizeBytes: result.sizeBytes });
      successCount += 1;
      if (!isSyllabus) found.get(subject)?.push(session);
      onEvent({
        type: "file",
        file: {
          filename,
          format: isSyllabus ? "syllabus" : "single",
          course,
          subject,
          session,
          url,
          sizeBytes: result.sizeBytes ?? 0,
        },
      });
    } else {
      if ("error" in result) errors += 1;
      onEvent({ type: "unavailable", entry: `${subject}_${session}` });
    }
    finishJob(subject);
  }

  const queue = [...jobs];
  await Promise.all(
    Array.from({ length: Math.min(DOWNLOAD_CONFIG.maxConcurrency, queue.length) }, async () => {
      while (queue.length > 0 && !signal?.aborted) {
        await runJob(queue.shift() as Job);
      }
    }),
  );
  if (signal?.aborted) return;
  if (successCount === 0 && errors > 0) {
    throw new Error("Could not reach the GTU server. Check your connection and retry.");
  }
  onEvent({
    type: "done",
    successCount,
    totalPdfs: subjects.length * (sessions.length + 1),
    processingTime: formatDuration(performance.now() - started),
  });
}

// ── Merging (module worker, main-thread fallback) ─────────────────────────

interface PendingMerge {
  resolve: (bytes: Uint8Array) => void;
  reject: (error: Error) => void;
}

type MergeResponse =
  | { id: string; ok: true; bytes: Uint8Array }
  | { id: string; ok: false; error: string };

const pendingMerges = new Map<string, PendingMerge>();
let mergeWorker: Worker | null = null;
let mergeWorkerBroken = false;
let nextMergeId = 0;

function getMergeWorker(): Worker | null {
  if (mergeWorkerBroken || typeof Worker === "undefined") return null;
  if (mergeWorker) return mergeWorker;

  try {
    const worker = new Worker(new URL("./merge-worker.ts", import.meta.url), {
      type: "module",
    });
    worker.addEventListener("message", (event: MessageEvent<MergeResponse>) => {
      const data = event.data;
      const entry = pendingMerges.get(data.id);
      if (!entry) return;
      pendingMerges.delete(data.id);
      if (data.ok) entry.resolve(data.bytes);
      else entry.reject(new Error(data.error));
    });
    worker.addEventListener("error", (event) => {
      mergeWorkerBroken = true;
      const error = new Error(event.message || "Merge worker failed.");
      for (const entry of pendingMerges.values()) entry.reject(error);
      pendingMerges.clear();
      worker.terminate();
      mergeWorker = null;
    });
    mergeWorker = worker;
    return worker;
  } catch {
    mergeWorkerBroken = true;
    return null;
  }
}

function mergeInWorker(parts: ArrayBuffer[]): Promise<Uint8Array> {
  const worker = getMergeWorker();
  if (!worker) return mergeOnMainThread(parts);

  return new Promise((resolve, reject) => {
    const id = `merge-${nextMergeId++}`;
    pendingMerges.set(id, { resolve, reject });
    try {
      // Transfer ownership: the caller only needs the merged result.
      worker.postMessage({ id, parts }, parts);
    } catch (error) {
      pendingMerges.delete(id);
      reject(error instanceof Error ? error : new Error("Merge worker failed."));
    }
  });
}

async function mergeOnMainThread(parts: ArrayBuffer[]): Promise<Uint8Array> {
  const { mergePdfParts } = await import("./pdf-merge");
  return mergePdfParts(parts);
}

async function mergeBlobs(blobs: Blob[]): Promise<Blob> {
  if (blobs.length === 0) throw new Error("None of these PDFs could be merged.");
  const parts = await Promise.all(blobs.map((blob) => blob.arrayBuffer()));

  let bytes: Uint8Array;
  try {
    bytes = await mergeInWorker(parts);
  } catch {
    // postMessage transfers (detaches) the buffers. If the worker failed
    // before using them, re-read the Blobs for the main-thread retry.
    const usable = parts.some((part) => part.byteLength > 0)
      ? parts
      : await Promise.all(blobs.map((blob) => blob.arrayBuffer()));
    bytes = await mergeOnMainThread(usable);
  }

  return new Blob([bytes as BlobPart], { type: "application/pdf" });
}

  if (cached) return cached;

  if (file.sources) {

    return buildOnce(file.filename, async () => {
      const blobs: Blob[] = [];
      for (const name of sources) {
        const blob = await loadSource(file.course, file.subject, name);
        if (blob) blobs.push(blob);
      }
      return mergeBlobs(blobs);
    });
  }

  const blob = await loadSource(file.course, file.subject, file.filename);
  if (!blob) throw new Error(`${file.filename} could not be downloaded. Retry.`);
  return blob;
}

function buildOnce(key: string, build: () => Promise<Blob>): Promise<Blob> {
  const existing = building.get(key);
  if (existing) return existing;
  const promise = build()
    .then((blob) => {
      cacheSet(key, blob);
      return blob;
    })
    .finally(() => building.delete(key));
  building.set(key, promise);
  return promise;
}

interface SelectionEntry {
  name: string;
  subject: string;
  session: string;
  file?: DownloadFileItem;
}

// Pure ordering rule for "Merge in order": every selected row expanded to its
// source papers, de-duplicated, then per subject: syllabus first, papers
// oldest → newest. Exported so the ordering is unit-testable without pdf-lib.
export function orderSelection(
  files: DownloadFileItem[],
  subjectsOrder: string[],
): SelectionEntry[] {
  const byName = new Map<string, SelectionEntry>();
  for (const file of files) {
    if (file.sources) {
      for (const name of file.sources) {
        const session = name.replace(/\.pdf$/i, "").split("_").pop();
        if (!session) continue;
        byName.set(name, { name, subject: file.subject, session });
      }
    } else if (file.session) {
      byName.set(file.filename, {
        name: file.filename,
        subject: file.subject,
        session: file.session,
        file,
      });
    }
  }

  const rank = (subject: string) => {
    const index = subjectsOrder.indexOf(subject);
    return index === -1 ? 999 : index;
  };

  return [...byName.values()].sort((a, b) => {
    if (a.subject !== b.subject) return rank(a.subject) - rank(b.subject);
    if (a.session === b.session) return 0;
    if (a.session === "SYLLABUS") return -1;
    if (b.session === "SYLLABUS") return 1;
    return chronoKey(a.session) - chronoKey(b.session);
  });
}

// "Merge in order": every selected row expanded to its source papers,
// de-duplicated, then per subject: syllabus first, papers oldest → newest.
export async function mergeSelection(
  files: DownloadFileItem[],
  subjectsOrder: string[],
): Promise<{ blob: Blob; filename: string; parts: number }> {
  const ordered = orderSelection(files, subjectsOrder);
  const course = files[0]?.course ?? "GTU";
  const blobs: Blob[] = [];

  for (const entry of ordered) {
    const blob = await loadSource(course, entry.subject, entry.name);
    if (blob) blobs.push(blob);
  }

  const subjects = [...new Set(ordered.map((entry) => entry.subject))];
  const filename =
    subjects.length === 1
      ? `${course}_${subjects[0] ?? "PAPERS"}_SELECTED_${blobs.length}.pdf`
      : `${course}_SELECTED_${blobs.length}_PAPERS.pdf`;
  return { blob: await mergeBlobs(blobs), filename, parts: blobs.length };
}

// Saves bytes as a file: same-origin blob URL + download attribute, so the
// browser saves it with this exact filename and stays on the page.
export function saveBytes(bytes: Uint8Array | Blob, filename: string, type = "application/pdf"): void {

// Shared PDF merge routine, used by the worker and the main-thread fallback.
// Loaded lazily: the app never pays for pdf-lib until a merge is requested.

import { PDFDocument } from "@cantoo/pdf-lib";

export async function mergePdfParts(parts: ArrayBuffer[]): Promise<Uint8Array> {
  const merged = await PDFDocument.create();
  let pages = 0;

  for (const part of parts) {
    try {
      const doc = await PDFDocument.load(part, { ignoreEncryption: true });
      const copied = await merged.copyPages(doc, doc.getPageIndices());
      copied.forEach((page) => merged.addPage(page));
      pages += copied.length;
    } catch {
      // A damaged source PDF is skipped instead of failing the whole merge.
    }
  }

  if (pages === 0) throw new Error("None of these PDFs could be merged.");
  return merged.save();
}

// In-memory sliding-window rate limiter for API routes.
// Stateless across instances, but sufficient abuse protection for this tool.
// (The visitor counter additionally uses Upstash's distributed limiter.)

interface Bucket {
  hits: number[];
  windowMs: number;
}

const buckets = new Map<string, Bucket>();
const MAX_BUCKETS = 5_000;

// Drops expired buckets, then evicts the least-recently-used ones. The old
// `buckets.clear()` wiped every client's limit as soon as one attacker
// created enough keys.
function evictIfNeeded(now: number): void {
  if (buckets.size <= MAX_BUCKETS) return;

  for (const [key, bucket] of buckets) {
    const last = bucket.hits[bucket.hits.length - 1] ?? 0;
    if (now - last >= bucket.windowMs) buckets.delete(key);
  }

  while (buckets.size > MAX_BUCKETS) {
    const oldest = buckets.keys().next();
    if (oldest.done) break;
    buckets.delete(oldest.value);
  }
}

// Returns true when the request is allowed; false when the limit is hit.
export function checkRateLimit(
  key: string,
  limit: number,
  windowMs: number,
): boolean {
  const now = Date.now();
  evictIfNeeded(now);

  let bucket = buckets.get(key);
  if (bucket) {
    // Refresh insertion order so the cap evicts the least recently used key.
    buckets.delete(key);
  } else {
    bucket = { hits: [], windowMs };
  }
  bucket.hits = bucket.hits.filter((hit) => now - hit < windowMs);
  buckets.set(key, bucket);

  if (bucket.hits.length >= limit) return false;
  bucket.hits.push(now);
  return true;
}

// Derives a client key from proxy headers.
//
// Prefer `x-real-ip` (set by Vercel and most reverse proxies). Otherwise use
// the LAST `x-forwarded-for` entry: the rightmost value is the one appended by
// the nearest trusted proxy, while the leftmost is client-controlled and
// trivially spoofed off-Vercel.
export function clientKey(
  headers: Headers,
  scope: string,
  fallback = "anon",
): string {
  const realIp = headers.get("x-real-ip")?.trim();
  const forwarded = headers.get("x-forwarded-for");
  const forwardedIp = forwarded
    ?.split(",")
    .map((part) => part.trim())
    .filter(Boolean)
    .at(-1);
  return `${scope}:${realIp || forwardedIp || fallback}`;
}

// Subject-code helpers: normalize free-text input into clean codes and
// detect the course embedded in newer prefixed codes (e.g. BE3150710).
// Used by the form, URL parsing, and deep-link routes.

import { COURSES } from "@/constants/app.constants";

const SEPARATOR = /[,\s;]+/;

// Splits raw user input ("3160704, 3160716") into unique uppercased codes.
export function parseSubjectCodes(raw: string): string[] {
  const seen = new Set<string>();
  for (const part of raw.split(SEPARATOR)) {
    const code = part.trim().toUpperCase();
    if (code.length === 0) continue;
    if (!seen.has(code)) seen.add(code);
  }
  return [...seen];
}

// Newer GTU codes start with the course and end in digits
// (BE3150710, DI03000031, BESP3150713). Longest match wins so BESP is not
// mistaken for BE and DISP is not mistaken for DI. Old numeric codes
// (3150713, 319283) return null and need a manually selected course.
export function courseFromSubjectCode(code: string): string | null {
  const upper = code.trim().toUpperCase();
  let match: string | null = null;
  for (const course of COURSES) {
    if (upper.length <= course.length || !upper.startsWith(course)) continue;
    if (!/^[0-9]+$/.test(upper.slice(course.length))) continue;
    if (!match || course.length > match.length) match = course;
  }
  return match;
}

// Distinct courses detected across all entered codes. More than one means
// the request mixes courses and cannot be fetched in a single run.
export function coursesFromSubjectCodes(codes: string[]): string[] {
  const found = new Set<string>();
  for (const code of codes) {
    const course = courseFromSubjectCode(code);
    if (course) found.add(course);
  }
  return [...found];

  });
  it("orders chronologically: summer before winter in a year", () => {
    expect(sortChronological(["W2024", "S2025", "S2024", "W2018"])).toEqual(["W2018", "S2024", "W2024", "S2025"]);
    expect(chronoKey("S2024")).toBeLessThan(chronoKey("W2024"));
  });
});

describe("progress", () => {
  it("does not count merged rows as probes", () => {
    let d = applyDownloadEvent(EMPTY_DOWNLOAD_RESPONSE, { type: "start", totalPdfs: 3 });
    d = applyDownloadEvent(d, { type: "file", file: { filename: "a", format: "single", course: "BE", subject: "X", session: "S2024" } });
    d = applyDownloadEvent(d, { type: "file", file: { filename: "m", format: "merge-all", course: "BE", subject: "X", sources: ["a"] } });
    expect(d.successCount).toBe(1);
    expect(pendingCountOf(d)).toBe(2);
  });

  it("start resets files, failures and counters", () => {
    let d = applyDownloadEvent(EMPTY_DOWNLOAD_RESPONSE, { type: "start", totalPdfs: 2 });
    d = applyDownloadEvent(d, {
      type: "file",
      file: { filename: "a", format: "single", course: "BE", subject: "X", session: "S2024" },
    });
    d = applyDownloadEvent(d, { type: "unavailable", entry: "X_W2024" });

    d = applyDownloadEvent(d, { type: "start", totalPdfs: 5 });

    expect(d.files).toEqual([]);
    expect(d.failed).toEqual([]);
    expect(d.successCount).toBe(0);
    expect(d.totalPdfs).toBe(5);
  });

  it("done replaces the running counters with final values", () => {
    let d = applyDownloadEvent(EMPTY_DOWNLOAD_RESPONSE, { type: "start", totalPdfs: 9 });
    d = applyDownloadEvent(d, {
      type: "done",
      successCount: 7,
      totalPdfs: 9,
      processingTime: "1.2s",
    });

    expect(d.successCount).toBe(7);
    expect(d.totalPdfs).toBe(9);
    expect(d.processingTime).toBe("1.2s");
    // No rows landed in this synthetic case, so all 9 probes still look pending.
    expect(pendingCountOf(d)).toBe(9);

  });

      ...EMPTY_DOWNLOAD_RESPONSE,
      totalPdfs: 1,
      failed: ["a", "b"],
    };
    expect(pendingCountOf(overDone)).toBe(0);
  });
